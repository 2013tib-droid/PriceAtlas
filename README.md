## Isi repo (Tahap 6b M0 + M5 + M1-harness + M4 + M2/M3 + mode pribadi D-100 + Tahap 7b produksi)

> **Mode pribadi (D-100):** default build mematikan foto (`NEXT_PUBLIC_PHOTO_CAPTURE`); struk masuk lewat `/tempel` sebagai JSON dari Gemini dan diproses worker tanpa AI (`EXTRACTOR=off`, `AI_MATCHER=off`, `ASK_ENGINE=off`). Menyalakan foto lagi: docs/06 §2.12.

- `supabase/migrations/` — sumber kebenaran skema; `db/schema.sql` adalah snapshot hasil generate (D-72). 6b M5: kuota Tanya (`app.ask_usage`, `begin_ask`, `record_ask_usage`) dan `app.ai_spend_today()`. 6b M4: `capture_item.read_member_*` + pemetaan ulang harga member di W18, R18 `item_status`/`thumbnail_path`/`vs_best_pct` tanpa record sesi, R20 `source_text`. 6b M2/M3: kunci confidence tier di `app.config` (`match_products` membaca config, hasil default identik), `app.ai_match_shortlist` (daftar pendek tier 4, hanya worker); `db/scripts/calibration_report.sql` (laporan kalibrasi, baca saja). 6b M2: masa kalibrasi `auto_save_min_confidence` = 1,01 + `calibration_started_on` (test memakai τ 0,90 dari `db/tests/lib/seed.sql`).
- `db/tests/` — harness SQL: `smoke.sql` (43 test Tahap 2, tidak diubah) + `flows/*` per alur.
- `apps/worker` — worker pipeline capture dan job (stub OCR/AI berbasis fixture). 6b M0: langkah gambar `prepareImages` (sharp + heic-decode: magic bytes, EXIF, metadata dibuang, ≤ 2576 px) untuk semua engine; klien Claude (`src/ai/`: timeout/retry/tenggat lease, structured outputs, pemetaan error, tabel harga), skema LLM + prompt v1 + konverter deterministik (`src/extractors/`), `VisionExtractor` (belum dipasang, `EXTRACTOR` tetap `stub`); fixture gambar = JPEG sintetis dari generator `eval/synthetic/`. 6b M1: harness uji OCR D-16 `eval/` (`pnpm --filter @priceatlas/worker ocr-eval init | annotate | run | score | report`: guard data F-117, split dev/test berstrata, lima arm, Message Batches + realtime, anggaran keras US$75, penyelarasan Hungaria + metrik §4.7, keputusan §4.8, laporan agregat tanpa teks, alat anotasi lokal), `OcrThenParseExtractor` + Google Cloud Vision, uji live sintetis `test:live` (manual). 6b M4: `STUB_FALLBACK_FIXTURE` khusus worker e2e, fixture `shopee-milo-uht` (confidence rendah). 6b M2/M3: `ClaudeAiMatcher` tier 4, matching screenshot nama produk + judul listing (Q-133), anggaran AI harian sebelum claim (`AI_DAILY_BUDGET_USD`), `CAPTURE_LEASE_SECONDS`, redaksi PII lapis 2–3. 6b M2: extractor dan matcher dipilih lewat env (`src/extractors/select.ts`: `EXTRACTOR=stub|vision|ocr+parse`, `AI_MATCHER=stub|claude`, kunci `WORKER_ANTHROPIC_API_KEY`, `EXTRACT_MODEL`, `EXTRACT_EFFORT_*`; cek kunci/model saat start), default tetap stub.
- `apps/web` — PWA Next.js 16: login OTP (`/masuk`), layout tab, service worker Serwist, `rpcCall`, formatter, pesan error; `POST /api/account/delete`. M1: beranda + cari (`/`, `/cari`), detail produk + cek harga rak (`/produk`), bandingkan ukuran (`/produk/ukuran`), lebih hemat di mana (`/produk/hemat`), scan barcode (`/kamera?jenis=barcode`). M2: sheet foto (`?sheet=foto`), kamera struk + galeri (`/kamera?jenis=struk|screenshot`), antrean foto offline (IndexedDB), unggahan (`/unggahan`) dan detailnya (`/unggahan/detail`). M3: konfirmasi struk (`/struk`), konfirmasi label/screenshot (`/konfirmasi`), pilih toko & cabang (`/lokasi`), pilih produk (lapisan `?pilih=produk`), produk baru (`/produk/baru`). M4: sesi belanja (`/belanja`, pilih cabang `/lokasi?mode=sesi`), banner sesi di semua layar, kamera label dengan jendela bidik (`/kamera?jenis=label`). M5: detail & koreksi harga (`/harga`, dari baris histori produk dan baris struk tersimpan), gabungkan produk (`/produk/gabung`), pisahkan produk (`/produk/pisah`), edit + hapus produk privat (`/produk/edit`), menu ⋯ detail produk. M6: onboarding (`/selamat-datang`, `/selamat-datang/member`), Saya (`/saya`: nama, ringkasan, Keluar + bersihkan data lokal), program member (`/saya/member`), berbagi harga publik (`/saya/berbagi`), privasi & hapus akun (`/saya/privasi`), tambah barcode/PLU di edit produk. ## Mulai cepat (mode A: PostgreSQL 17 lokal, tanpa Supabase)

```bash
pnpm install
export PGHOST=localhost PGUSER=postgres PGPASSWORD=postgres
bash db/tests/run.sh                         # semua test SQL
pnpm -r --workspace-concurrency=1 test       # test TypeScript
db/scripts/dev-db.sh                         # database dev + user uji + katalog contoh
```

Frontend (butuh Supabase CLI, mode B):

```bash
supabase start                               # PostgreSQL 17, Mailpit di http://127.0.0.1:54324
# isi apps/web/.env.local dari `supabase status` (docs/06 §4.1)
pnpm --filter @priceatlas/web dev            # http://localhost:3000/masuk
```

Langkah lengkap (worker, fixture, mode B, frontend, L4, e2e): [`docs/06-local-dev.md`](docs/06-local-dev.md).
