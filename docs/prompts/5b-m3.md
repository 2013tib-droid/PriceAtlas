Catatan lingkungan (docs/07 §1.4–§1.6, docs/06 §4.5):
- `supabase start` tidak jalan di lingkungan cloud (CDN image Docker diblokir). Verifikasi Supabase,
  L4, db-types, worker terhadap Supabase, dan e2e dilakukan di job CI `supabase-e2e`.
- PostgreSQL 17 lokal untuk L1–L3: paket npm @embedded-postgres/linux-x64 17.x sebagai server
  (salin `native/` ke folder yang bisa diakses user non-root, buat symlink dari pg-symlinks.json,
  initdb sebagai user non-root, jalankan dengan `-k /var/run/postgresql,/tmp`). psql 16 bawaan cukup
  sebagai klien.
- Playwright lokal: PW_CHROMIUM_PATH=/opt/pw-browsers/chromium-*/chrome-linux/chrome (WebKit tidak ada
  lokal). L5c: `pnpm --filter @priceatlas/web test:browser` dengan PW_CHROMIUM_PATH yang sama.
- e2e bisa dicoba lokal lewat "Supabase tiruan" kecil (auth OTP + subset PostgREST + Storage, di atas
  DB mode A + worker mode A dengan LocalBlobStore, F-39/§1.6). Untuk M3 perlu diperluas: PATCH
  dengan filter updated_at + Prefer return=representation, filter ilike untuk search store. Tetap
  jangan di-commit.
- Pelajaran M2: WebKit menolak Blob di IndexedDB pada sesi ephemeral (F-48); toast setelah navigasi
  keluar layar penuh memakai lib/flash.ts (F-42); di e2e tunggu sampai data tersimpan sebelum
  navigasi; Next route announcer juga ber-role alert.
- Artefak CI (blob storage) tidak bisa diunduh dari lingkungan ini; baca log job lewat GitHub.
- Hindari `pkill -f` dengan pola yang juga ada di baris perintah sendiri. Pakai `fuser -k 3000/tcp`.
